# CONTROL-PID-AGRO---ELECTIVA
Grupo para CONTROL PID (AGRO)
===============================================================================================
Perspectiva del producto
===============================================================================================
El proyecto se plantea como una herramienta didáctica para facilitar la enseñanza y aplicación práctica del control PID digital. Su uso principal será en laboratorios de mecatrónica y sistemas de control, donde estudiantes y profesores podrán experimentar con la estabilización de sistemas. Además, se busca que sea portátil, mantenible y adaptable a futuras aplicaciones educativas.
